# Sistema-Biblioteca
Sistema de Biblioteca simples envolvendo usuários e bibliotecários.

## Sobre o Projeto
- Um Sistema de Biblioteca simples que envolve usuários e bibliotecários, além de gerenciar e pedir empréstimos em livros.

### Objetivo do Projeto
Criar um sistema que gerencia livros em uma biblioteca, desde adicionar ou retirar livros, ver quem pediu empréstimos, e observar prazos de devolução.
